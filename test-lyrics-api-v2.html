GET /api/lyrics/{songId} MEJORADO

Obtener letras de una canción con archivos y sincronizaciones por variante

Query params: voiceType=SOPRANO|CONTRALTO|TENOR|BAJO|TODOS_LOS_CORISTAS|main
PUT /api/lyrics/{songId}/text MEJORADO

Actualizar letras de texto para una variante específica

Body: { content: string, voiceType?: VoiceType|null }
POST /api/lyrics/{songId}/file MEJORADO

Subir archivo de letras (PDF, DOC, DOCX, TXT, JPG, PNG) - Compartido entre variantes

GET /api/lyrics/{songId}/sync MEJORADO

Obtener letras sincronizadas por variante de voz

Query params: voiceType=SOPRANO|CONTRALTO|TENOR|BAJO|TODOS_LOS_CORISTAS|main
PUT /api/lyrics/{songId}/sync MEJORADO

Actualizar sincronización de letras por variante

Body: { syncData: Lyric[], voiceType?: VoiceType|null }
DELETE /api/lyrics/{songId}/file/{fileId} NUEVO

Eliminar archivo específico de letras
