GET /api/lyrics/{songId}

Obtener letras de una canción específica

PUT /api/lyrics/{songId}/text

Actualizar letras de texto (tipo TEXT)

POST /api/lyrics/{songId}/file

Subir archivo de letras (PDF, DOC, DOCX, TXT)

DELETE /api/lyrics/{songId}

Eliminar letras de una canción

GET /api/lyrics/{songId}/sync

Obtener letras sincronizadas línea por línea

PUT /api/lyrics/{songId}/sync

Actualizar sincronización de letras
